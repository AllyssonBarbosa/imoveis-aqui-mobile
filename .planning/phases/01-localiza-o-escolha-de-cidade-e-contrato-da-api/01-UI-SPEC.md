# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Localização, Escolha de Cidade e Contrato da API.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Framework note:** this is a Flutter/Dart project (mobile + Windows/macOS desktop), not a
> React/Next.js/Vite project. The shadcn initialization gate does not apply. The design system
> is Material 3, native `material.dart` widgets, `ColorScheme.fromSeed` — mandated as a
> non-negotiable constraint in `.claude/CLAUDE.md` and `instruções.md`. This document adapts the
> UI-SPEC template's intent (design tokens, component inventory, copy contract) to that stack.
>
> **UI surface of this phase:** an optional location-permission priming screen, and a single
> city-selection screen that renders as 5 sealed-state variations (message + CTA change per
> state) plus a top-of-screen city switcher. `API-01` (the frozen contract doc) is a non-UI
> deliverable — no UI needed for it.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside list rows and CTAs |
| sm | 8px | Compact spacing — between notice text and the CTA below it |
| md | 16px | Default spacing — `Card`/`ListTile` internal padding, gap between list rows |
| lg | 24px | Section padding — priming screen content block, screen horizontal padding |
| xl | 32px | Gap between the state header/notice block and the city list |
| 2xl | 48px | Gap above the priming screen's primary CTA |
| 3xl | 64px | Top spacing above the priming illustration/icon on tall screens |

Exceptions: minimum touch target is **48dp** (Material 3's minimum interactive target size), not
the 44px web/iOS default — applies to the tappable city-name header (LOC-05) and any icon-only
affordance (e.g., a leading location icon that is itself tappable).

## Color

`ColorScheme.fromSeed` derives `surface`/`secondaryContainer`/`error`/etc. algorithmically from a
single seed — the hex values below for Dominant/Secondary are the *illustrative* tones that seed
produces at default light-mode tonal steps, not hardcoded literals to paste into the theme. Per
`.planning/research/PITFALLS.md` Pitfall 15: pass `brightness: Brightness.light` explicitly (no
stated dark-mode requirement) and verify `onPrimary`-on-`primary`, `onSurface`-on-`surface`, and
the auto-generated `error`/`onError` pair for WCAG AA (4.5:1) once real widgets render — don't
hand-pick a different red.

**⚠️ Note:** no exact seed hex is defined anywhere upstream (`PROJECT.md`/`CONTEXT.md` only say
"Verde e Branco" + `ColorScheme.fromSeed`) — the value below is a researcher default, not a
user-locked decision. Confirm it (or replace it) before it's committed to the shared
`app_theme.dart`, since every later phase inherits this seed.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `ColorScheme.surface` — derived from seed, ≈ `#FFFBFF` at default light tonal step | Screen background on both the priming and city-selection screens |
| Secondary (30%) | `ColorScheme.secondaryContainer` / `surfaceContainer` — light green tonal surface, derived from seed | `Card` backgrounds (city rows), priming-screen icon backdrop |
| Accent (10%) | `ColorScheme.primary` — seed color, default proposal `Color(0xFF2E7D32)` (Material Green 800) | Reserved for: `FilledButton` fill ("Usar minha localização"), the active/selected indicator on the top-of-screen city chip, the location icon when in an active/positive state |
| Destructive | `ColorScheme.error` — Material-default red, auto-generated by the seed, never hand-picked | Not used in Phase 1 (no destructive actions in LOC-01..06 scope) — reserved for a future phase that introduces one |

Accent reserved for: the priming screen's primary CTA fill, the top-of-screen city-name chip's
selected/active indicator, and the location icon in its "active" state. Never used for body
text, default `Card` backgrounds, or the state-header/notice text.

## Copywriting Contract

This phase's UI is 5 sealed-state variations of one screen (D-07) plus one priming screen (D-05).
Rows below cover both. Verbatim rows are taken directly from `01-CONTEXT.md`; drafted rows are
this researcher's proposed default copy (not independently user-locked) and are marked as such.

| Element | Copy | Source |
|---------|------|--------|
| Priming screen heading | "Vamos te levar direto pra sua cidade" | drafted |
| Priming screen body | "Usamos sua localização só para abrir o app já na cidade certa. Você pode trocar quando quiser." | drafted |
| Priming screen Primary CTA | "Usar minha localização" — `FilledButton`, triggers the native OS permission prompt (D-05) | **verbatim, D-05** |
| State: `authorized` + served (D-10) | Top header shows `"{Cidade}, {UF}"` (Display role) — no separate heading copy; entry is direct, no confirmation step | **verbatim, D-10** |
| State: `authorized` + not served (D-11) | Notice: "Ainda não atendemos [Cidade] — escolha uma das disponíveis" + full city list below | **verbatim, D-11** |
| State: `denied` (soft) | Heading: "Escolha sua cidade" — no apology notice, treated as the normal path (LOC-03) | drafted |
| State: `deniedForever` | Heading: "Permissão de localização bloqueada. Ative nas Ajustes do aparelho, ou escolha sua cidade abaixo." + CTA "Ativar localização nas Ajustes" (`TextButton`, opens `geolocator.openAppSettings`) + full city list | Heading drafted; CTA copy **verbatim, D-06** |
| State: `location-service-off` | Heading: "Ative a localização do aparelho para entrarmos direto na sua cidade, ou escolha abaixo." + full city list | drafted |
| State: geocoding failure (D-12) | Notice: "Não conseguimos identificar sua localização automaticamente. Escolha sua cidade abaixo." + full city list (same light-notice treatment as not-served) | drafted |
| Loading (in-flight GPS/geocoding) | "Localizando você…" under a centered `CircularProgressIndicator` | drafted |
| Top city switcher (all screens once a city is set) | `"{Cidade}, {UF}"` — tappable, accessible label "Trocar cidade" (LOC-05) | drafted, structure per D-10 |
| Empty state | Not applicable — the city list is a bundled asset (D-13/D-16), never empty at runtime | n/a |
| Error state | See the geocoding-failure and `deniedForever` rows above — never a dedicated error screen, always a fallback to the city list (LOC-06) | n/a |
| Destructive confirmation | None this phase — switching city is a direct, reversible, single-tap action; no confirmation dialog | n/a |
