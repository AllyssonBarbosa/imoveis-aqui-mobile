## Capture procedure (canonical — 05-07 and 05-18 reuse it)

Never against the user's Web/.env database. In ../imoveis-aqui/Web: `CAPTURA_DB="sqlite:///${TMPDIR:-/tmp}/imoveis_captura_05.sqlite3"`; delete that scratch file first if it exists; run `DEBUG=True DATABASE_URL="$CAPTURA_DB" .venv/bin/python manage.py migrate --noinput` and `... semear_vitrine_dev`; start `DEBUG=True ALLOWED_HOSTS=localhost,127.0.0.1,10.0.2.2 DATABASE_URL="$CAPTURA_DB" .venv/bin/python manage.py runserver 127.0.0.1:8000 --noreload` in the background; poll `curl -sf http://127.0.0.1:8000/api/publico/cidades/` until it answers (max ~30 s); from the app repo root run `python3 tool/capturar_fixtures_api.py http://127.0.0.1:8000 test/fixtures/api --grupo <grupo>`; then stop that background server. Ids are deterministic for a fresh scratch DB seeded by the same command.
