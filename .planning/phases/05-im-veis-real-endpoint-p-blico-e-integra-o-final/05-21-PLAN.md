## Assumption delta (vs. 05-CONTEXT.md)

- D-08 (endpoints públicos sem token, `authentication_classes = []`) assumia acesso anônimo ilimitado. **Mudou:** continua sem token, mas com limite por IP (429). O app não tem tratamento especial para 429: vira o mesmo estado de erro com "Tentar de novo" (D-14 — o app não compensa; nenhuma mudança em `lib/`, provada no 05-22).
- **Novo:** `NUM_PROXIES = 0` por padrão. Atrás de proxy reverso em produção, todos os visitantes aparecem com o IP do proxy até alguém configurar `NUM_PROXIES` — item de deploy, registrado no contrato e no README pelo 05-22.
- **Novo:** o limite usa o `LocMemCache` padrão (por processo). Com vários workers o limite efetivo multiplica — aceito no nível 1 do ASVS; cache compartilhado é item de deploy, registrado.
- **Novo:** operadoras móveis usam CGNAT (muitos aparelhos num IP). 120/min por IP é folgado para a navegação de uma pessoa, mas um IP compartilhado pode bater no limite — risco aceito, ajustável por `VITRINE_TAXA_ANONIMA` sem código.
