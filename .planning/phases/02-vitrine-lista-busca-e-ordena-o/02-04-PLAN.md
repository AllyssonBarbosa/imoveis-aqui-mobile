<objective>
Swap the city list's source from the bundled asset to the real public endpoint built in plan
02-02 (VIT-06), with a Dio module reading `API_BASE_URL` (D-17), removing the asset and the local
data source so there is a single source of truth (D-16), letting saved-city visitors enter even
when the endpoint is down, and making the app actually able to reach a development server on
Android (INTERNET + debug-only cleartext) and iOS (local networking).

Purpose: success criterion 5 of the phase — the selector lists cities from
`GET /api/publico/cidades/` — via the DI swap Phase 1 prepared (F1/D-14).
Output: `ModuloRede`, `CidadeRemoteDataSource`, updated repository/use case/screen, native
network config, README section, tests; asset/local source deleted.
</objective>

<user_story>
**As a** visitante, **I want to** escolher entre as cidades que o servidor diz estarem atendidas
hoje, e ainda assim abrir direto na minha cidade salva se o servidor estiver fora, **so that** a
lista nunca diverge do site e eu nunca fico travado numa tela de erro.
</user_story>
