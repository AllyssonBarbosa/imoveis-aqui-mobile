| Property | Value |
|----------|-------|
| **Framework** | App: flutter_test + bloc_test ^10.0.0 + mocktail ^1.0.5 · Web: `django.test` / DRF `APITestCase` (Django 5.2.17, DRF 3.18.1) |

## Sampling Rate

- **After every task commit:** `flutter test <arquivos tocados>` (app) / `manage.py test <classe tocada>` (web)
- **After every plan wave:** `flutter analyze` + `flutter test` (app, **à mão** — o gate pós-merge do GSD não detecta testes Flutter, D-14) e `manage.py test <apps tocados>` (web)
- **Before `/gsd-verify-work`:** as duas suítes completas verdes + UAT no emulador com o Django rodando e `semear_vitrine_dev` (D-15)
- **Max feedback latency:** ~240 s
