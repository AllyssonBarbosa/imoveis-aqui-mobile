# Phase 07.1 — Security

> Contrato de segurança da fase: registro de ameaças, riscos aceitos e trilha de auditoria.
> A fase mexe em dois repositórios: o app (`imoveis-aqui-mobile`, main 48eb08b) e a API Django
> (`Imoveis-aqui/Web`, main d9ddd8f). As duas `feat/APP07` já estão mergeadas nas respectivas mains.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| app -> API Django | a DataSource remota consome JSON e URLs `next` vindos do servidor | dado não confiável (páginas, URL de paginação) |
| visitante anônimo -> API pública Django | rotas `corretores/<id>/imoveis/` e `empresas/<id>/imoveis/` sem token; `pk` e query string são entrada | entrada não confiável |
| banco multitenant -> serializer público | só o recorte da vitrine (`na_vitrine()`) e a allowlist do cartão podem sair | dados de imóveis de várias empresas |
| páginas da API -> lista na tela | o acervo pode mudar entre páginas; o app não decide recorte | ids e ordem do servidor |
| respostas da API (404/429/500) -> tela | erro não pode vazar dado velho nem disparar requisição em laço | estado de erro |
| script de captura -> servidor Django local | a captura só toca um SQLite temporário semeado | dados fictícios do seed |
| documentação versionada -> equipe | contrato, README e UAT não carregam segredo do ambiente local | nomes de variável, dados fictícios |
| repositório git local -> origin | merge e commits só publicados com autorização (D-13) | código |
